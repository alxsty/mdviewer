Markdown Viewer PWA

Apri un file .md dal dispositivo. L’app renderizza il documento in sola lettura, crea l’indice dagli heading e permette di copiare righe o blocchi dal sorgente.

Per file da qualche MB il parsing viene eseguito in un Web Worker, così l’interfaccia rimane usabile.

Righe

Click su una riga per selezionarla. Shift+click per estendere l’intervallo. Click su un blocco renderizzato per agganciare le sue righe sorgente.
